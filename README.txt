Tailwind CSS – Acme Rockets

Project Overview
This project is part of my Advanced JavaScript course, where I am exploring different web development technologies. I am learning how to use Tailwind CSS by following a tutorial by Dave Gray and building a responsive website called Acme Rockets.

Technologies and Tools
- HTML5
- Tailwind CSS v3
- Node.js and npm
- Visual Studio Code
- Tailwind CSS IntelliSense
- Inline Fold
- Prettier
- Live Server

What I Am Learning
- Using Tailwind utility classes instead of writing traditional CSS.
- Creating responsive layouts for mobile and desktop screens.
- Using Flexbox to position and align elements.
- Adding light and dark mode styling.
- Creating navigation menus and styled components.
- Using npm commands and scripts.

Tutorial Credit
Dave Gray – Build a Website with Tailwind CSS | Project Tutorial

This project is being created for educational purposes and to gain hands-on experience with Tailwind CSS.
